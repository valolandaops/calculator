# 🧮 Hello Easy Calculator Demo

A lightweight, interactive web application built with HTML5, CSS3, and JavaScript/TypeScript logic. 
Designed to demonstrate DOM manipulation, mathematical operations, edge-case error handling, and a custom Easter egg feature.

---

## ✨ Features

* **Basic Arithmetic:** Supports Addition (`+`), Subtraction (`-`), and Multiplication (`*`).
* **Division Handling:** Supports standard division (`/`) and integer floor division (`//`).
* **Zero Division Protection:** Automatically catches divide-by-zero attempts with a user-friendly safeguard message (`"No I Cannot divide by zero!"`).
* **Easter Egg:** Includes a custom sentiment operation (`+-` / `"Feeling Bad(D:)"`) that returns a supportive response (`"Everything is gonna be ok!"`).
* **Clean UI:** Built with a modern, responsive card layout using CSS Flexbox.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, custom form components)
* **Logic:** JavaScript / TypeScript (Control flow, DOM event handlers, switch statements)
